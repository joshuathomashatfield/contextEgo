# Methodology

Observation timestamps are decoder presentation timestamps in seconds. Videos are decoded sequentially without using native FPS to infer time. The sampler emits the first decoded observation at or after each sampling-grid threshold, skipping missed thresholds rather than duplicating images. Backends with missing/nonmonotonic PTS fail explicitly. Intervals are half-open [start,end); exact end belongs to the next segment. Gaps and unknown (-1) intervals are excluded from classification and censor segmentation. Overlaps, nonfinite features and nonmonotonic observations are rejected.

At t, the window is all observations in [t-W,t], inclusive at both ends. W=0 selects the latest available observation. There is no padding or resampling. At regular 2 Hz, a full 1/2/5/10 second window contains 3/5/11/21 observations; startup windows have fewer. Mean pooling averages actual observations; optional GRU consumes the variable-length window and uses its last hidden state. GRU state resets for each window, while procedural memory persists within a video.

For K steps and bounded last H=16 predictions, previous memory is the one-hot latest decoded prediction, initially zero. Full history concatenates latest one-hot (K), normalized visit frequencies over the last H predictions (K), and normalized ordered adjacent transition counts (K?). Total dimension 2K+K?. Visits divide by history length; transitions divide by history length minus one, with safe zero initialization. Repeated predictions and backward or graph-unexpected transitions are retained. History is bounded, so this is a summary of full available memory rather than an unbounded exact transcript. The representation is identical across runs.

Procedural graphs are validated knowledge artifacts separate from predicted state. They are currently descriptive and do not mask logits or impose forward progression. Thus this implementation studies learned history fusion; graph-prior or explicit constraint effects require a separately calibrated extension. A linear head concatenates pooled/GRU visual features with procedural memory. Trainable parameter counts are reported because memory dimensions differ.

Training uses sequential per-observation Adam updates. Current prediction is made before the current supervised update, detached, optionally decoded, then appended to memory. Evaluation uses frozen models and model predictions exclusively; no teacher-forced history is used. Memory and decoder are constructed afresh per video. Statistics are fit on training videos only. Highest validation mean video macro F1 selects the checkpoint. This simple online-style training protocol is a baseline; feature observations are not shuffled within videos.

Decoders: none returns argmax; majority uses the last N raw predictions and resolves ties toward the most recent; confirmation changes the current state only after N identical consecutive raw predictions (first prediction initializes immediately). Main matrix fixes none. Secondary decoder comparisons must use validation for settings. Raw and decoded predictions are saved; smoothing delays can be compared with the raw timeline without conflating model evidence latency.

Classification uses labeled observations only. Macro F1 averages over every procedure class, including absent classes as zero. Per-class precision/recall and confusion are reported. Segment runs extend from an observation timestamp to the next observation, with the last ending at annotated video duration. This is observation-grid evaluation, not sub-frame temporal precision. Unknown truth intervals censor predictions and break segments. Segment matching greedily selects highest temporal IoU among equal-label pairs, one-to-one, at thresholds .1/.25/.5. Repetitions remain separate segments.

Boundaries are changes between two known adjacent labels. Match only equal directed transitions (old,new), within tolerance (default 1s), greedily taking the globally nearest unmatched pair. This is a documented greedy procedure, not maximum-cardinality matching. No video-start boundary is scored. Delays are signed predicted time minus true time, conditional on matches within tolerance; missed transitions and unmatched false transitions are also reported. Early detection yields negative delay. False transitions per minute divide unmatched predictions by labeled observation-span duration. A recognized new step does not establish successful completion of the old one.

Bootstrap intervals resample participant clusters (averaged within participant), falling back to videos when absent. Matrix comparisons use paired differences on the same test videos before cluster resampling. Adjacent observations are never independent bootstrap units. These percentile intervals are descriptive and are not multiple-comparison-adjusted hypothesis tests. At least several independent participants and repeated seeds are needed for research.

Cached inference timing synchronizes CUDA and includes window construction, memory, device transfer, forward pass and decoding; excludes encoder and feature loading. Training and evaluation wall times, cache extraction totals, throughput and peak CUDA allocation are separate. End-to-end timing is null because extraction and evaluation are separate commands. Do not add cached timing to extraction totals as if it were a measured streaming runtime.
